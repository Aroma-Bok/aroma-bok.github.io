## 안녕하세요, Aroma-Bok입니다

**"선 조치 후 분석"** — 문제를 먼저 해결하고, 왜 그랬는지 끝까지 파고들어 기록합니다.

Java / Spring 기반 웹 개발로 시작해, 지금은 **RAG·LLM 기반 AI 서비스**를 공부하고 만들고 있습니다.
이 블로그는 개발하면서 부딪힌 오류, 개념 정리, 직접 해 본 실습을 모아 두는 곳입니다.
