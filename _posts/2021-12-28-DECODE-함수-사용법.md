**DECODE 함수는 '오라클'쿼리에서 가장 많이 쓰이는 함수중 하나라고 한다.**

**프로그래밍에서의 'if else'와 비슷한 기능을 수행한다.**

**DECODE(Column, 조건1, 결과1, 조건2, 결과2, .....)**

```html
INSERT INTO A ( A )
VALUES ( DECODE(#{A}, '', 'N')
```

**\=> 'A테이블'에 'A컬럼'이 '공백'이면 'N'을 'insert'한다.**
