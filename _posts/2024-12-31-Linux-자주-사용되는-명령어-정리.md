### **1\. 파일 및 디렉토리 관리**

```bash
ls : 디렉토리 내용 목록 출력
옵션 : -l (상세정보), -a (숨김 파일 포함)

cd : 디렉토리 이동
예 : cd /home/user

pwd : 현재 작업 디렉토리 경로 출력

mkdir : 디렉토리 생성
예 : mkidr new_folder

rm : 파일/디렉토리 삭제
옵션 : -r (디렉토리 삭제), -f(강제 삭제)
예 : rm -rf folder

cp : 파일/디렉토리 복사
예 : cp source.txt destination.txt

mv : 파일/디렉토리 이동 또는 이름 변경
예 : mv /home/user/source.txt /home/user/to/source.txt - 파일/디렉토리 이동
예 : mv source.txt new_source.txt - 이름 변경
*경로를 지정하지 않으면 현 위치를 Defualt로 한다

touch : 빈 파일 생성
예 : touch newfile.txt

find : 파일/디렉토리 검색
예 : find / -name "*.txt"

cat : 파일 내용 출력
예 : cat file.txt

more, less : 긴 파일 내용을 페이지 단위로 출력
예 : more file.txt - 위에서 아래로 이동하면서 읽기 가능
예 : less file.txt - 위에서 아래, 아래에서 위로 읽기 가능

head, tail : 파일의 처음/끝 일부 내용 출력
예 : head -n 10 file.txt - 문서의 머리 부분 10줄 출력
예 : tail -n 10 file.txt - 문서의 끝 부분 10줄 출력
예 : tail -f file.txt - 문서의 끝 부분 10줄씩 출력하면서 파일늬 내용 실시간 감시
* n 옵션으로 출력하고 싶은 라인 수르 입력 가능 (Default는 10줄)
* f 옵션을 사용하면 파일의 내용을 실시간으로 감시
```

### **2\. 파일 권한 및 소유권**

```bash
chmod : 파일/디렉토리 권한 변경
예 : chmod 755 file.txt

chown : 파일/디렉토리 소유자 변경
예 : chown user:group file.txt - file.txt에 대해서 소유자와 그룹명을 변경
예 : chown user file.txt - file.txt에 대해서 소유자 변경
예 : chown :group file.txt - file.txt에 대해서 그룹명 변경
```

### **3\. 프로세스 관리**

```bash
ps : 현재 실행중인 프로세스 목록 출력
옵션 : aux (모든 사용자, 상세 정보)

top : 실시간 시스템 상태 및 프로세스 정보

htop : top의 대화형 대안 (별도 설치 필요)

kill : 프로세스 종료
예 : kill -9 PID_No

jobs : 현재 쉘에서 실행중인 백그라운드 작업 확인

fg : 백그라운드 작업을 포그라운드로 가져옴

bg : 백그라운드로 작업 실행
```

### **4\. 시스템 정보 확인**

```bash
uname : 시스템 정보 확인
옵션 : -a (전체 정보 출력)

df : 디스크 사용량 확인
예 : df -h

du : 파일/디렉토리 크기 확인
예 : du -sh folder/

free : 메모리 사용량 확인
예 : free -h

uptime : 시스템 실행 시간 및 부하 확인

whoami : 현재 사용자 이름 출력

id : 사용자 ID 및 그룹 정보 출력
```

### **5\. 네트워크**

```bash
ping : 네트워크 연결 상태 확인
예 : ping google.com

ipconfig / ip addr : 네트워크 인터페이스 정보

netstat : 네트워크 연결 상태 확인

curl : URL에서 데이터 요청
예 : curl http://example.com

wget : 파일 다운로드
예 : wget http://example.com/file
```

### **6\. 압축 및 아카이브**

```bash
tar : 파일/디렉토리 압축 및 해제
압축 : tar -czvf archive.tar.gz folder/
해제 : tar -xzvf archive.tar.gz

zip, unzip : ZIP 파일 생성/해제
예 : zip -r archive.zip folder/

gzip, gunzip : GZIP 압축/해제
예 : gzip file.txt
```

### **7\. 사용자 관리**

```bash
who : 현재 로그인한 사용자 목록 출력

adduser : 새 사용자 추가
예 : adduser new_user

passwd : 사용자 비밀번호 변경
예 : passwd user_name

su : 다른 사용자로 전환
예 su - user_name - 다른 사용자의 계정으로 100% 전환, 전환된 사용자의 환경설정을 불러와 적용
예 su user_name - 현재 사용자를 로그아웃하지 않은 상태에서 다른 사용자의 계정으로 전환

sudo : 관리자 권한으로 명령 실행
```

### **8\. 기타 유용한 명령어**

```bash
history : 이전 명령어 기록 확ㅇ;ㄴ

alias : 명령어 단축키 설정
예 : alias = ll='ls -la'

echo : 텍스트 출력
예 : echo "Hello World"

crontab : 작업 예약
예 : crontab - e

scp : 파일복사
예 : scp file.txt user@remote:/path

rsync : 파일 동기화
예 : rsync -av source/ destination/
```

### **리눅스 위치 개념**

```bash
/ : 루트 디렉토리
/home : 사용자 홈 디렉토리
/etc : 설정 파일
/var : 로그 파일
/usr : 사용자 프로그램 및 라이브러리
```
