요즘 회사에서 DB를 들여다보면 NVL함수가 많이 보인다.

학원에서는 배운 적이 없기 때문에 당연히 나는 몰랐던 함수라서 궁금해했다.

그래서 오늘은 NVL 함수에 대해서 정리해보려고 한다.

* * *

#### **NVL 함수 (오라클에서만 제공)**

**: 해당 컬럼의 값이 null 인 경우에, 특정값으로 출력하고 싶으면 NVL함수를 사용한다.**

**그리고 해당 컬럼의 값이 null 인 경우와 아닌 경우를 지정하여 특정값으로 출력하고 싶으면 NVL2 함수를 사용한다.**

```sql
SELECT NVL(A, B) as NVL_INDEX
FROM A;

SELECT NVL2(A, B(null 아닌 경우), C(null인 경우)) as NVL_INDEX  
FROM A;
```

**A 라는 테이블에, A라는 컬럼이 있다고 가정하고, 그 값을 조회하려 할 때,**  
**그 값이 null 값이면 B로 변경해주는 함수 이다.**  
  
**추가적으로, A라는 컬럼의 값이 null이거나 null이 아닌경우를 지정하여 값을 치환할 수 있다.**  
**NVL2함수를 사용하면 가능하다.**  
  
**1) A값이 null인 경우 => NVL\_INDEX = C**  
**2) A값이 null이 아닌 경우 => NVL\_INDEX= B**

**결론 : null값을 특정값으로 치환 = NVL, null인 경우와 null이 아닌 경우를 지정해서 치환 = NVL2**
