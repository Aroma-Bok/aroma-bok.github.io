**리눅스(Linux)의 파일과 디렉토리 권한은 소유자(Owner), 그룹(Group), 기타(Other) 사용자에 따라  
접근 제어를 설정하는 시스템이다. 권한은 파일 및 디렉토리에 대한 읽기, 쓰기, 실행 작업을 제어한다.**

* * *

#### **권한 예**

```bash
-rwxr-xr--
```

#### **파일 유형**

-   **\- :일반 파일**
-   **d : 디렉토리**
-   **l : 심볼릭 링크**
-   **c : 문자 장치 파일**
-   **b : 블록 장치 파일**

#### **권한**

-   **r (read) : 읽기 권한**
-   **w (write) : 쓰기 권한**
-   **x (execute) : 실행 권한**
-   **각 권한은 소유자, 그룹, 기타 사용에 대해 각각 설정**

#### **권한 순서**

-   **첫 번째 : 소유자의 권한**
-   **두 번째 : 그룹의 권한**
-   **세 번째 : 기타 사용자의 권한**

```bash
rwx | rwx | rwx
```

#### **예시**

```bash
rwx r-x r--

소유자 : 읽기, 쓰기, 실행
그룹 : 읽기, 실행
기타 : 읽기
```

#### **권한 변경 명령어**

```bash
chmod [권한] [파일/디렉토리]

예 : chmod 755 myfile
소유자 : rwx - 7
그룹 : r-x - 5
기타 : r-x - 5

결과 : 사용자는 rwx, 그룹과 기타 사용자는 r-x
```
